# Naija Whot

Play Naija Whot in your browser. Play against the computer, or create a game and share the 4-character code with friends to play online (2 to 4 players).

## Play
Open the GitHub Pages link for this repository.

## Publish on GitHub Pages
1. Upload `index.html` (and this README) to the main branch of your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick **main** and **/(root)**, then Save.
4. After a minute your game is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## House rules
Pick Two / Three stacking, cards dealt, 1 Hold On, 14 General Market, no finishing on a special card and a turn timer can all be switched in the game under **House rules**.

## Notes
- Online play uses PeerJS and needs an internet connection. The player who creates the game is the host, and the game ends if the host leaves.
- Files: `index.html` is the whole game (images included).
